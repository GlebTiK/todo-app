# Todo Back-end

This backend uses [**NestJS**](https://nestjs.com/) with [**TypeORM**](https://github.com/typeorm/typeorm), [**PostgreSQL**](https://www.postgresql.org/), and [**JWT**](https://en.wikipedia.org/wiki/JSON_Web_Token) to provide authentication and management of user created to-do tasks.

## Local development

```bash
npm install
cp .env.example .env
npm run start:dev
````
